# What the update prompt says. One plain-language line per change; the first four are shown.
New: Atlas 2.0 checks that an update really came from Atlas before it installs - updates are now signed. Older versions cannot check this themselves, so 2.0 is the first update protected this way.
New: safer by design - Atlas's own folders are protected from its own file tools, changes to which folders and cloud providers it trusts need your OK in a Windows box, and cloud keys never leave the address you chose.
New: Atlas can tell when something did not really happen - after creating, deleting or changing things it reads the result back and says "Confirmed" or "Not confirmed", and multi-step tasks (Settings, Tasks) can be stopped with F8 and picked up again.
New: Settings, Stats shows what Atlas has done and what cloud AI has cost, kept only on this PC, with spend limits that pause cloud AI before it surprises you.
New: a private search address (SearXNG) can be used first for web research, with Atlas's built-in search as the fallback.
Improved: models that support tools or structured answers are asked in that form, with one repair attempt, so local and cloud models make fewer mistakes planning actions.
Improved: talking and small talk go to the connected model when it can converse, with a clear fallback if it cannot, and Atlas knows what it can really do.
Improved: your Nova session now lives in Windows Credential Manager, and the provider list is held natively - Atlas migrates both on first start and keeps a backup.
